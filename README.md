### 🅿️ [Qt Parking System — STM32 연동 주차 관리 시스템](https://github.com/Kyuhyeon34/QT-Parking-system_QT5)

<img src="https://img.shields.io/badge/C%2B%2B-00599C?style=flat-square&logo=cplusplus&logoColor=white" alt="C++"> <img src="https://img.shields.io/badge/Qt%205-41CD52?style=flat-square&logo=qt&logoColor=white" alt="Qt 5"> <img src="https://img.shields.io/badge/OpenCV%20DNN-5C3EE8?style=flat-square&logo=opencv&logoColor=white" alt="OpenCV DNN"> <img src="https://img.shields.io/badge/SQLite-003B57?style=flat-square&logo=sqlite&logoColor=white" alt="SQLite"> <img src="https://img.shields.io/badge/STM32F411-03234B?style=flat-square&logo=stmicroelectronics&logoColor=white" alt="STM32F411"> <img src="https://img.shields.io/badge/UART-0078D4?style=flat-square" alt="UART">

- **펌웨어:** HAL 없이 CMSIS 레지스터와 직접 작성한 링커 스크립트·스타트업 코드로 STM32F411을 구동합니다.
- 초음파 센서로 차량을 감지하고, TIM5 PWM으로 차단기 모터를 움직입니다. `Handler → StateMachine → Controller` 3계층으로 상태(`US_ON` / `US_OFF` / `MOTOR`)를 관리합니다.
- **Qt 앱:** 카메라 스레드에서 OpenCV DNN(ONNX)으로 번호를 인식하고, 입·출차 기록과 요금을 SQLite에 저장합니다.
- UART 텍스트 프로토콜로 이벤트·거리·상태를 주고받고, `make` 한 번으로 펌웨어 빌드·플래시와 Qt 빌드를 함께 처리합니다.

### ⚙️ [STM32F411 Motor Project](https://github.com/Kyuhyeon34/STM32F411_Motor_Project)

<img src="https://img.shields.io/badge/C-A8B9CC?style=flat-square&logo=c&logoColor=white" alt="C"> <img src="https://img.shields.io/badge/STM32F411-03234B?style=flat-square&logo=stmicroelectronics&logoColor=white" alt="STM32F411"> <img src="https://img.shields.io/badge/Timer%20%2F%20PWM-555555?style=flat-square" alt="Timer / PWM"> <img src="https://img.shields.io/badge/FSM-654FF0?style=flat-square" alt="FSM"> · 팀 프로젝트

- 버튼 **숏클릭 / 롱클릭**과 UART 명령(`F` / `R` / `S`)으로 DC 모터의 정회전·역회전·정지를 제어합니다.
- `STOP` / `FORWARD` / `REVERSE` 상태 머신과 이벤트별 함수 포인터 테이블로 입력을 처리합니다.
- HAL 없이 레지스터로 PLL 96MHz 클럭, TIM5 PWM(속도), TIM4 1ms 틱, TIM2 원샷(롱클릭 판정), USART2 RX 인터럽트를 설정했습니다.
- 사용한 레지스터·핀·함수를 [Notion 문서](https://blushing-addition-5ca.notion.site/v3-0-3a51d46c18fc80859512f7798826be27?pvs=74)로 정리했습니다.

### ⏱️ [Basys3 Stopwatch — 스톱워치·시계 2모드 타이머](https://github.com/Kyuhyeon34/basys3-stopwatch)

<img src="https://img.shields.io/badge/Verilog%20HDL-654FF0?style=flat-square" alt="Verilog HDL"> <img src="https://img.shields.io/badge/Vivado-ED1C24?style=flat-square&logo=amd&logoColor=white" alt="Vivado"> <img src="https://img.shields.io/badge/Basys%203-555555?style=flat-square" alt="Basys 3">

- 버튼으로 **분·초 시계 / 스톱워치(1/100초)** 모드를 전환하고, 4자리 FND를 시분할로 구동합니다.
- 스톱워치는 `STOP ⇄ RUN` FSM으로 동작하고, 5초 동안 입력이 없으면 FND 원형 애니메이션(`ANIM`) 상태로 넘어갑니다.
- 10ms 버튼 디바운서와 틱 생성기를 모듈로 분리하고, 테스트벤치로 동작을 확인했습니다.
